## 阅读与编辑

从上表打开课件 PDF 即可阅读。需要下载整套资料时，可在仓库首页选择 **Code → Download ZIP**。

Markdown 源文件采用 Marp 排版，公式由 MathJax 渲染。可使用 VS Code 的 Marp for VS Code 扩展预览，课件图片位于各次课目录下的 `img/` 中。
